Import character data assets

Unreal .uasset files are binary — the browser can’t open them raw. Copy each DA’s dialogue array as text (one file per character), then drop them here.

  1. Open a character DA (Child, Girl, GuardWomen…)
  2. Click the dialogue array property in Details
  3. Ctrl+C / Cmd+C
  4. Paste into a text file named after the character, e.g. Child.txt
  5. Drop all those .txt files below (or paste one at a time)
